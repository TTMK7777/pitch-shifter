# Pitch Shifter

再生中の動画・音楽の **ピッチ（音程）だけ** をリアルタイムに上下する Chrome 拡張機能。
再生速度は一切変えません。

ブラウザ上で再生される `<video>` / `<audio>` に Web Audio API を挿し込み、
ピッチシフトと簡易 EQ・ステレオ拡張を適用します。**外部通信ゼロ・データ収集ゼロ**、
すべてブラウザ内で完結します。

| 項目 | 内容 |
|------|------|
| 種別 | Chrome 拡張機能 (Manifest V3) |
| バージョン | 1.0 |
| 実装 | 素の JavaScript のみ（ビルド不要・依存パッケージなし） |
| ピッチ可変幅 | −1200 〜 +1200 セント（±1 オクターブ）、1 セント刻み |
| 外部通信 | なし |

## 想定ユースケース

- **楽器・歌の練習** — 原曲を自分の声域やギターのチューニングに合わせて移調する
- **耳コピ / 採譜** — 半音単位で動かして音程を確認する
- **語学・聴き取り** — 声の高さを変えて聞き取りやすさを調整する

いずれも「速度を落とさずに音程だけ変えたい」場面を想定しています。
速度変更はブラウザ標準の再生速度機能で行えるため、本拡張は扱いません。

## 機能

### ピッチ調整

- スライダーで −1200〜+1200 セントを **1 セント刻み** で調整
- ボタン操作: `▲/▼ 半音`（±100¢）、`±10¢`、`±1¢`、`リセット`
- 現在値をセント値と半音換算の両方で表示

### ピッチエンジンの切替

| エンジン | 方式 | 特性 |
|---------|------|------|
| **Jungle**（既定） | ディレイ変調グラニュラー | 軽量・低遅延。大きくずらすと微かな揺らぎが出る |
| **WSOLA** | 波形相似オーバーラップ加算 | 高音質・揺らぎが少ない。やや高遅延・高負荷。切替直後に一瞬無音 |

WSOLA の AudioWorklet の読み込みに失敗した場合は、自動的に Jungle へフォールバックします。

### 音質強化

| つまみ | 範囲 | 実装 |
|--------|------|------|
| 低音 | ±12 dB | lowshelf @ 200 Hz |
| 中音 | ±12 dB | peaking @ 1 kHz (Q=0.9) |
| 高音 | ±12 dB | highshelf @ 3.5 kHz |
| ステレオの広がり | 0〜200% | M/S マトリクス（0=モノラル, 100%=原音, 200%=最大） |

`音質強化をリセット` で EQ とステレオ幅のみを初期化します。

## インストール

Chrome ウェブストアには未公開のため、開発者モードで読み込みます。

1. `chrome://extensions` を開く
2. 右上の **デベロッパーモード** をオン
3. **パッケージ化されていない拡張機能を読み込む** をクリックし、このフォルダを選択

### 更新（コード変更後）

1. 拡張カードの **⟳（再読み込み）** を押す
2. 対象タブを **F5** でリロードする

## 使い方

ツールバーのアイコンからポップアップを開き、つまみを操作するだけです。

**動作の前提**: ピッチ処理は「メディアが再生された瞬間」に対象へアタッチされます。
つまみを動かしても変化しない場合は、**一度再生を開始してから**操作してください。
（ポップアップ操作時にも、その時点で再生中の要素へ改めてアタッチを試みます）

## 権限とプライバシー

### 送信されるデータ

**ありません。** 本拡張はネットワークリクエストを一切行いません。
音声データ・閲覧履歴・操作内容のいずれも、収集・保存・送信しません。
音声処理はすべてブラウザ内の Web Audio API 上で完結します。

### 要求している権限

| 権限 | 用途 |
|------|------|
| `activeTab` | ポップアップ操作時に、現在のタブへ設定値を送るため |
| `scripting` | content script が未注入のタブへ、操作時に注入するため |
| `storage` | **現在未使用**（[既知の制限](#既知の制限)参照） |
| `host_permissions: <all_urls>` | 動画・音楽サイトを事前に限定できないため、全サイトで動作させる目的 |

`<all_urls>` は広い権限ですが、**用途は再生中の `<video>` / `<audio>` への音声処理のみ**です。
DOM の読み取り・改変や、ページ内容の送信は行いません。

## 既知の制限

| # | 内容 | 状態 |
|---|------|------|
| 1 | **設定が保存されない**。タブをリロードするとピッチ・EQ は初期値へ戻る。`storage` 権限は宣言だけで未使用 | 確認済み |
| 2 | **設定はタブ単位**。複数タブで別々の値になる | 確認済み |
| 3 | 音質強化（EQ / ステレオ幅）は**ページ内の全メディアで共有**。1 セットのつまみが全要素に効く | 確認済み（設計上の意図） |
| 4 | **リミッター未搭載**。低音を大きく上げると歪む場合がある。歪んだら低音を下げる | 確認済み |
| 5 | WSOLA のピッチ比は内部で 0.25〜4.0 にクランプされる（スライダー範囲 ±1オクターブ = 0.5〜2.0 なので実用上は影響なし） | 確認済み |
| 6 | 1 つのメディア要素に対し `createMediaElementSource` は 1 回しか呼べない。他の拡張が先に掴んでいると本拡張は無効になる | 確認済み |
| 7 | DRM 保護コンテンツ（Netflix 等）や、CORS 未許可のクロスオリジン音源では無音化する可能性がある — **未検証。Web Audio 一般の挙動からの推測** | 未検証 |

### 公開前に対応すべき項目（メモ）

- 上記 #1: `storage` 権限は「未使用なら削除」「使うなら設定永続化を実装」のどちらかに寄せる。
  未使用権限はウェブストア審査で指摘対象になり得る
- アイコン（`icons/`）が未同梱。ウェブストア公開には必須
- スクリーンショット未用意

## アーキテクチャ

```
manifest.json          Manifest V3 定義
content.js             ページに注入。音声グラフの構築と制御（本体）
popup.html / popup.js  操作 UI とメッセージ送信
soundtouch-worklet.js  SoundTouchJS 公式 AudioWorklet（WSOLA エンジン／無改変同梱）
```

### 音声グラフ

```
<video> / <audio>
  └ MediaElementSource
      └ ピッチエンジン（Jungle ネイティブノード群 ⇄ WSOLA worklet を切替）
          └ 低音(lowshelf) → 中音(peaking) → 高音(highshelf)
              └ ステレオ拡張(M/S マトリクス)
                  └ destination
```

設計上の要点は 2 つです。

1. `createMediaElementSource` は要素ごとに 1 回しか呼べないため、エンジン切替時は
   **ソースを保持したまま下流の配線だけを張り替える**
2. 音質強化チェーンは **全要素で共有**（1 セットのつまみが全メディアに効く）

より詳しい内部設計は [`docs/architecture.md`](docs/architecture.md) を参照してください。

### ピッチ方式

- **Jungle**: ディレイ変調によるグラニュラー方式。半音から内部パラメータへの校正には
  soundbank-pitch-shift の 5 次多項式を使用
- **WSOLA**: SoundTouchJS の波形相似オーバーラップ加算。`pitch` AudioParam に
  ピッチ係数 `2^(cents/1200)` を設定

## 開発

ビルド不要です。ファイルを編集し、拡張を再読み込みするだけで反映されます。

```
編集 → chrome://extensions で ⟳ → 対象タブを F5
```

### デバッグ

- **content script**: 対象ページの DevTools コンソール。`[PitchShifter]` プレフィックスで
  アタッチ状況とフォールバックを出力
- **popup**: ポップアップを右クリック →「検証」

### メッセージ契約（popup → content）

| type | ペイロード | 動作 |
|------|-----------|------|
| `SET_PITCH` | `{ factor }` | ピッチ係数を全要素へ適用 |
| `SET_ENGINE` | `{ engine: 'jungle' \| 'wsola' }` | エンジン切替（非同期応答） |
| `SET_EQ` | `{ eq: { bass, mid, treble } }` | EQ を dB で設定 |
| `SET_STEREO` | `{ width }` | ステレオ幅を倍率で設定（1.0=原音） |
| `GET_STATE` | — | 現在の `factor` / `engine` / `eq` / `width` を返す |

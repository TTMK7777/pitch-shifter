# Code of Conduct / 行動規範

This project adopts the **Contributor Covenant, version 2.1** as its code of conduct.

- Full text (English): https://www.contributor-covenant.org/version/2/1/code_of_conduct/
- 日本語訳: https://www.contributor-covenant.org/ja/version/2/1/code_of_conduct/

## Enforcement / 通報先

| Situation | Contact |
|---|---|
| Report about a participant | [Private report to the maintainers](../../security/advisories/new) (visible to maintainers only) |
| Report about the maintainer | [GitHub report abuse](https://github.com/contact/report-abuse) |

Reports are handled confidentially in line with the Covenant's enforcement guidelines.

参加者に関する通報はメンテナのみが閲覧できる上記の private report から、メンテナ自身に関する通報は GitHub の report abuse からお願いします。
